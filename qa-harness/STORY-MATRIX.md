# Story matrix: Yappr Mobile 1.0 (141 PRD stories)

One row per PRD story (`docs/mobile/PRD.md` section 8), in PRD order. Generated by `bin/lib/stories.py matrix`;
the orchestrator fills Verdict / Proof / Defects as stream reports arrive.

- **Tier:** A = EXECUTION §7 exit-matrix row (see Exit row), B = core-risk depth, C = data/write flows, D = secondary,
  E = accessibility (edge battery E-xx is in QA-PLAN §3).
- **iOS / Android:** the owning stream and depth (D = full depth, S = smoke, N/A = impossible on that platform; see Notes).
  Tier A rows are also smoke-checked in the opposite theme by the partner lane (QA-PLAN §4).
- **Verdicts:** PASS · PASS+ (works, defects noted) · FAIL · BLOCKED (reason) · N/A · N/R (not run yet).
- **Proof:** paths under `evidence/` (screenshots, videos, ui-text dumps, log greps). A verdict without a path is not a result.
