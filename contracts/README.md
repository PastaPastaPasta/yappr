# Yappr Data Contracts

Dash Platform data contracts used by the Yappr dapp. The JSON here is the
source of record for what was registered; deployed contract ids live in
`lib/constants.ts` (testnet defaults) and the `.env.*` files (per-deployment
overrides).

## Social contract

| File | Status |
|------|--------|
| `yappr-social-contract-v2.json` | **Deployed** on testnet (`9oDC6xdg…`, staging/prod). 16 document types + the YAPP token. Topology `v2`: replies chain through a polymorphic `parentId`; like/repost/bookmark/quote share one `postId` keyspace. The on-chain copy has since gained the optional `post.embedContractId`/`embedDocType`/`embedId` fields via `scripts/update-social-contract.mjs`. |
| `yappr-social-contract-v4.json` | **Superseded** by v5 on the moutai devnet, kept as the input `scripts/build-v5-contract.py` transforms. The v3 interaction topology (flat threads, `likeReply`, posts-only repost/bookmark, dual quote fields, `refersTo` everywhere) plus the like overhaul: indexOnly `like`/`likeReply`, inline `post.hashtag` (`''` = untagged), poster-attested `author` fields. Needs protocol v14. |
| `yappr-social-contract-v5.json` | **Deployed** on the moutai devnet (`BQrC6mu3…`, the /devnet build), generated by `scripts/build-v5-contract.py` from the v4 file. v4 plus the dev.7 aggregate-index grammar: `hashtag` optional (61-char ceiling, the `''` sentinel dies), `skipIfAbsent` on `byHashtagPost`, rankedCountable at-forms for trending tags and the creator leaderboard, a plain `byAuthorTimePost` sibling, and the ranked follow chain. Needs protocol v14 on 4.2.0-dev.7. |

The topology differences are wired into the app through
`lib/contract-topology.ts` and selected per deployment with
`NEXT_PUBLIC_CONTRACT_TOPOLOGY`.

Historical drafts (`-actual`, `-clean`, `-ready`, `-deploy`, `-updated`,
`-v3-draft`, `-v3-topology`, and the unsuffixed original) were removed
2026-08-31; recover them from git history if ever needed.

## Feature contracts

- `yappr-profile-contract.json` — unified profile contract (avatar/banner live here, not in the social contract)
- `yappr-dm-contract.json` — encrypted direct messages
- `yappr-blog-contract.json` — long-form blog posts, comments, follows
- `yappr-storefront-contract.json` — stores, items, orders, reviews, shipping
- `yappr-vault-contract.json` — contract-bound encryption keys + encrypted storage
- `yappr-auth-vault-contract.json` — auth vault + access grants
- `encrypted-key-backup-contract.json` — passphrase-encrypted key backups
- `key-exchange-v2.json` — QR login key-exchange protocol
- `pollr-contract-v3.json` — polls (deployed); `pollr-contract-v2.json` is the abandoned predecessor, kept for the on-chain id record

## Legacy (merged into the social contract)

- `yappr-hashtag-contract.json`, `yappr-mention-contract.json`,
  `yappr-block-contract.json` — early standalone contracts whose document
  types were folded into the social contract
- `yappr-minimal.json` — minimal post+profile scratch contract for SDK testing
