# Historical contract and deployment notes

These are superseded designs, SDK upgrade investigations and deployment
records. They describe the code and networks at the time they were written;
their scripts, contract files, network ids and commands may no longer exist.
Use the [release record](../TESTNET_RELEASE.md), [current contract index](../../contracts/README.md)
and [non-social reference](../NON_SOCIAL_CONTRACTS.md) for current work.

Sakura's current [beta.6 deployment](../SAKURA_BETA6_DEPLOY.md),
[social v16](../SOCIAL_V16.md), and [storefront v9](../STOREFRONT_V9.md)
stay outside this archive because `.env.devnet` still selects them.

Some current devnet feature grammar (blog v8, pollr v7 and DM v5) was
established by the archived upgrade records. The current deployment and
non-social reference link to that historical evidence where it still applies.

Social v10–v15 remain authoritative for rules that v16/v17 do not change,
including v10 media fingerprints and v13 `report.box` encoding. Follow the
current specs for later overrides.
