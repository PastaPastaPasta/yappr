# y-glyph

Two rounded voices, with different weights, converge above a shared reply stem.
The open junction and asymmetry distinguish the mark from a tuning fork.
The geometric lowercase yappr uses a flowing y descender and equal pp spacing.

Colors: #0369a1, #0ea5e9, #38bdf8, white. No additional chromatic accent.
App-icon background: #0369a1.
All lettering and artwork are hand-authored paths; no font conversion.
Wordmark baseline: 45.5 in its 64-unit viewBox, including the rounded stroke edge.
Weakness: at 16px the separate voices reduce to an asymmetric y silhouette.
